# Nikolay NPC voice clips

Twelve synthesized Russian voice clips for the current BLIGAN RP quest line.
Voice: ru-RU-DmitryNeural; rate -8%, pitch -8 Hz.

| File | Dialogue |
| --- | --- |
| 00-greeting.mp3 | Greeting |
| 01-quest.mp3 through 09-quest.mp3 | Current quest explanations, in menu order |
| 10-reward.mp3 | Quest reward |
| 11-finale.mp3 | Quest line completed |

`replicas.json` contains the spoken text. `nikolay_voice.cfg` maps dialogue slots to direct audio URLs and can be placed in the SA-MP server's `scriptfiles/` directory.

Clips are generated speech, not recordings of a real voice actor. No game mode source code or server credentials are included.
